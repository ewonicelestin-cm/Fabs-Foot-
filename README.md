# 🏆 Sports Predictions AI  
  
Application de pronostics sportifs en temps réel alimentée par l'IA sur Vercel.  
  
## 🚀 Fonctionnalités  
  
- ✅ Pronostics IA en temps réel avec streaming  
- ✅ Scores en direct avec WebSockets  
- ✅ Mise à jour automatique toutes les 10 minutes  
- ✅ Leaderboard des prédicteurs  
- ✅ Interface moderne et responsive  
- ✅ Déploiement automatique sur Vercel  
  
## 📋 Prérequis  
  
- Node.js 20+  
- Compte Vercel  
- Clé API OpenAI  
- Base de données PostgreSQL  
- Redis (optionnel)  
  
## 🛠️ Installation  
  
```bash  
# Cloner le repo  
git clone <repo-url>  
cd sports-predictions-ai  
  
# Installer les dépendances  
npm install  
  
# Configurer les variables d'environnement  
cp .env.example .env.local
